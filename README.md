# Doorbell

A webhook gap finder for PayPal: it listens to a shop's PayPal webhooks, finds the deliveries the shop lost, says why, and asks PayPal to send them again. Built for the PayPal AI Hackathon on Devpost.

This first commit publishes one file, `docs/planning/eval/SEAL.md`: the hashes of the evaluation sets, committed before any model is run on them, so that the order of commits can be checked later. The code follows in a later commit.

Hosted demo (PayPal Sandbox, a fictional shop, test money only): https://paypal-doorbell.vercel.app
